# Blogify — Full Stack MERN Blogging Platform

A modern blogging platform built with the MERN stack where users can register, log in, create blogs, upload cover images, edit and delete their own blogs, search content, and manage posts from a personal dashboard.

### Tech Stack

* React + Vite
* Tailwind CSS
* Node.js + Express
* MongoDB Atlas
* JWT Authentication
* Cloudinary
* Render + Vercel

### Features

* Secure authentication with JWT cookies.
* Create, update, and delete blogs.
* Cloudinary image uploads.
* Search and category filtering.
* Pagination.
* User dashboard.
* Responsive UI.
